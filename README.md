# Sistem Klasifikasi Data dengan Himpunan

## Deskripsi
Aplikasi untuk mengklasifikasikan data
menggunakan operasi himpunan Python.

## Fitur
1. Union
2. Intersection
3. Difference
4. Complement
5. Diagram Venn otomatis
6. Prinsip Inklusi-Eksklusi
7. Pengujian dua dataset

## Teknologi
- Python
- Matplotlib
- Matplotlib-Venn

## Cara Menjalankan
pip install -r requirements.txt

python main.py
